# Cheat Sheet

## Git Commands
- `git clone` downloads a repository to you computer, including the history.
- `git pull` downloads changes that have been made since you last cloned or pulled.
- `git add` moved changes from your working copy to the staging area.
- `git commit` adds a new commit to the repository history, with all the staged changes.
- `git branch` shows branches
- `git chechout` switches and creates branches
- `git switch` does the same with a slightly different interface
- `git merge` merges 2 branches together
- `git push ` copies commits from local to remote

# Workflow

1. `git pull` to get latest commits from the remote
2. `git checkout -b feature` create a branch to work safetly on your feature
3. edit files in an editor
4. `git add` to get ready to commit
5. `git commit -m "..."` to save your changes
6. `git checkout main && git merge feature` switch back to main and merge your feature
7. `git push` send your work to everybody else.
